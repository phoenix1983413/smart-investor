Agent 设计模式

作者：设计模式 · 所属分类：AI 与技术

核心内容总结

把软件工程“设计模式”的思想迁移到 Agent 时代：不管用什么框架，可靠的 Agent 系统反复出现同一些结构——本篇是对这些结构的技术总纲式梳理。

主线是“感知 → 推理 → 行动”循环（Perception-Reasoning-Action），以及围绕它的工具调用、记忆、规划与多 Agent 协同等模式。

主要章节与观点梳理

  • 感知-推理-行动循环Agent 的最小闭环：获取环境信息 → LLM 推理决策 → 执行动作 → 观察结果再进入下一轮。所有模式都是这个循环的变体。
  • 工具调用把模型“会说不会做”补齐为“会做”：函数注册、参数生成、结果回填，是 Agent 与真实世界交互的通道。
  • 记忆分层工作记忆（上下文窗口）、短期记忆（会话状态）、长期记忆（向量库/知识图谱）——分层设计决定成本与能力上限。
  • 多 Agent 协同当单 Agent 上下文与职责过载时，按角色/流程拆分为多个 Agent 协作；代价是通信复杂度与一致性挑战。
