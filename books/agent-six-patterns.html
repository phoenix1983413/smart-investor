核心内容总结

六大 Agent 设计模式的工程化落地指南：不止讲“是什么”，更讲在真实系统里怎么选、怎么组合、怎么避开常见坑。

六大模式涵盖 ReAct、工具使用、规划执行、反思、多 Agent 协同等核心范式（完整名单与对应关系以原文为准，待补充）。

主要章节与观点梳理

  • ReAct推理与行动交错：让模型边想边做，每步先输出思考再调用工具，可解释性与纠错能力更强。
  • 工具使用从函数签名设计、参数校验到错误兜底的完整工程规范——工具质量决定 Agent 上限。
  • 规划与执行分离Plan-and-Execute：先产出任务计划再逐步执行，适合长任务；需要处理计划失效后的重规划。
  • 反思模式执行后自我评审（Reflection），把错误反馈进下一轮——用额外推理成本换质量，适合高价值产出。
  • 多 Agent 协同角色分工（规划者/执行者/评审者）+ 消息传递协议；警惕“多 Agent 表演”，协同必须有明确的信息流。
  • 工程化选型模式组合优于单模式炫技：先单 Agent 走通，再按瓶颈逐个引入模式。
