核心内容总结

一本“名词词典 + 概念地图”：把 Agent 领域的常见术语放在同一框架里定义清楚，避免讨论时各说各话。

适合作为团队内部对齐口径的基础读物——先统一语言，再统一架构。

主要章节与观点梳理

  • 感知（Perception）Agent 从环境获取信息的方式：用户输入、API 返回、文档检索、传感器数据等，一切决策的输入端。
  • 推理（Reasoning）以 LLM 为核心的思考过程：理解意图、分解任务、选择策略——Agent 的“大脑”。
  • 规划（Planning）把目标拆解为可执行步骤：任务分解、依赖排序、动态重规划。
  • 记忆（Memory）短期（上下文）与长期（外部存储）记忆；记忆的写入、检索与遗忘策略。
  • 工具使用（Tool Use）通过函数调用与外部系统交互的能力：搜索、计算、读写数据库、执行代码。
  • 自主性程度从“每步都问人”到“完全自主”，自主性是光谱而非开关，越高越要配护栏。
