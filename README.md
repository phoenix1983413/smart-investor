## 概览

这是一个单页静态网站，用深色金融杂志风格呈现《聪明的投资者》核心思想：

- 投资 vs 投机的边界

- 安全边际
- 防御型 vs 积极型投资者
- 七条防御型选股标准
- PE × PB ≤ 22.5 公式
- 十条现代投资者启示
